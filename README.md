Data We Collect
To provide its core functionality, the Bot may collect and store the following information: • User Identifiers: Discord User IDs,steam id, usernames, and avatars. • Server Identifiers: Discord Server (Guild) IDs, channel IDs, and role IDs. • Configuration & Usage Data: Custom server settings, command usage logs, prefix configurations, and user-submitted content required for specific features (e.g., reminders, economy balances, or leveling stats). • Message Content: We do not log or permanently store regular chat messages. Message content is only processed temporarily in memory when explicitly required to execute a command (if the Message Content Intent is enabled).

Data Storage and Security
• All stored data is kept on secure servers with restricted access. • We do not sell, rent, trade, or share your personal data with any third parties. • Data is retained only for as long as necessary to provide the Bot's services or until the Bot is removed from a server.
